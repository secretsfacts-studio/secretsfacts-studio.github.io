Privacy Policy

Shorts Uploader · Last updated: November 22, 2026

What this app does

Shorts Uploader is a personal tool that uploads videos to YouTube channels owned by its operator. It uses the YouTube Data API (YouTube API Services). By using this app you also agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Data we access

When an account owner signs in with Google, the app requests one permission: upload videos to your YouTube channel (youtube.upload). The app does not read your email, contacts, viewing history, comments or any other account data.

How data is used and stored

  • The access token Google issues is stored only on the operator's own computer and is used only to upload videos the operator created.
  • No user data is sold, shared with third parties, used for advertising, or transferred anywhere else.
  • Shorts Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can remove this app's access at any time at myaccount.google.com/permissions (or via the Google security settings page). Deleting the app's stored token from the operator's computer also ends access.
